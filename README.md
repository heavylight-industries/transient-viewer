# transient-viewer

A transient detector (TKEO) running in the browser: **https://heavylight-industries.github.io/transient-viewer/**

Open it and it starts on two built-in examples. Load your own samples (files or a whole folder) to see where
the detector finds transients, compare the three slice pickers (VOL, GRID, RAND), and click a slice to hear it.
Everything runs in the page; nothing is uploaded.
